Claude Code Ticket Management System

This project is a ticket management application being developed with Claude Code, designed to streamline support workflows with integrated AI agents and bots. The system is planned to help organize tickets, automate routine handling, and improve response efficiency.

A key part of the application is a set of AI agents that can read email, interpret incoming requests, and support the creation or routing of tickets based on message content.
