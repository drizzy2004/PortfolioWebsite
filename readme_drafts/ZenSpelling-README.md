# Zen Spelling

Zen Spelling is an educational web application designed to help students in grades 1-5 improve spelling through interactive gameplay and guided practice.

## Overview

This project combines learning activities, student-friendly design, and classroom-oriented features into a single platform built to make spelling practice more engaging.

## Highlights

- Interactive spelling-focused gameplay
- Student profiles and learning flows
- Teacher-support features
- Designed for elementary learners
- Built as a collaborative team project

## Tech Stack

- Django
- Python
- HTML
- CSS
- JavaScript

## Purpose

Zen Spelling was built to explore how educational software can be both useful and enjoyable, while also supporting role-based classroom workflows.
